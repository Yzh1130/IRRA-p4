## 1. 最终方法（冻结）

### 1.1 流程

| 模块 | 做法 | 拟合在哪里 |
|---|---|---|
| ① 可用性感知打分与校准（B★） | 每个图库项只用它现有的模态打分（drop-blank）；完整、仅红外、仅 RGB 三种可用性各一组 Platt 参数 | 开发集同质分数 |
| ② 通用近邻重排前端（α-QE/DBA） | αDBA：图库项嵌入换成前 k_d 个近邻的加权平均，权重 max(cos, 0)^α，α = 3。文本查询扩展：t′ = norm(t + β·Σ w_j e′_j)，取 B★ 后验最高的 k_q 项，w_j ∝ P^α。变换后按可用性重新拟合 Platt | 开发集模拟图库；配置按 §3.3 的规则选 |
| ③ 红外身份链接图 | 含红外的图库项之间，用收缩 WCCN 映射后的余弦作链接 | 1076 个训练身份的干净红外特征 |
| ④ 来源存在性门控 | r_j = σ(β₀ + β₁z(f1F_j) + β₂z(Δ_j) + β₃z(κ̂) + β₄z(p̂_I))。f1F 是到完整项的最大链接余弦；Δ = f1F − f1I；κ̂ 是可用性在链接图上的 Coleman 同质性指数；p̂_I 是仅红外占比 | 开发集上 60 个可用性 episode；标签 = 是否存在同身份完整项 |
| ⑤ 定向凸后验迁移 | P′_qj = (1 − r_j)·P_qj + r_j·Σ_k a_jk·P_qk，k 取完整项，a_jk = softmax_k(κ_a·c_jk)。只改仅红外项的列；r_j ≤ 1 − 10⁻⁶；并列时保持输入顺序 | κ_a 在开发 episode 上选 |

- **本文方法（Ours）= ①→②→③④⑤**，代码中的方法名是 QE+M：在 QE-DBA 的后验上做 A-2f-ctxn 的迁移。迁移权重只取决于链接和可用性，与前端分数无关。
- 模块 ③–⑤ 自第十三轮跑前登记以来没有改过。

### 1.2 事后选择的声明

- 前端选 α-QE/DBA，是看过第十四轮开发集结果之后定的。
- 选择用的是中性准则：在所有"通用重排 + 迁移"的组合中，非探针混合的平均 ΔmAP 最高。按这个准则，QE+M 在两种选择规则、两个 base 种子上都排第一。
- 第十四轮的去留规则判为不通过：s102 的路线 2 (ii) 为 −0.15，容差 −0.10。
- 所以本次测试是对一个事后定下的流程做一次性确认。论文中照实写明。

### 1.3 可证性质（写进论文，不靠测试；都是相对前端输出而言）

- 迁移只改仅红外项的分数，完整项与仅 RGB 项的分数等于前端输出。
- 前端 top-1 不是仅红外项的查询，迁移后 top-1 不变（凸组合上界加 r_j < 1；第十三轮 §3.5）。
- 门控全部拒绝（r ≡ 0）、图库中没有完整项、或没有仅红外项时，输出等于前端输出。
- 迁移权重与前端无关，所以同一组权重可以叠加在任意前端上。
- 每个查询的计算量是 O(|J|·|F|)，J、F 分别是仅红外项和完整项。

## 4. 比较的方法

| 类别 | 方法 | 说明 |
|---|---|---|
| 本文 | **QE+M** | §1 |
| 打分基线 | Raw、DB、B★ | Raw：缺失模态用空白图编码后融合，不校准；DB：drop-blank，不校准；B★：drop-blank 加按可用性 Platt |
| 通用后处理（联合嵌入空间） | KR、RVN、QE-DBA | k-reciprocal（Zhong 等 2017）的文本查询版；NAFS 的视觉近邻重排（Gao 等 2021）；αDBA + αQE（Gordo 等 2017；Radenović 等 2018） |
| 通用后处理（同一红外链接图） | KRir、RVNir、QEir、GP-same | 近邻与权重改用和本文相同的链接余弦；GP-same 是链接图上的对称传播 |

| 框架消融（同一前端） | QE+CAET、QE+SRC2f、QE+EM、QE+Orc | 依次是：不设拒绝的竞争式迁移；只用局部证据的门控；门控的图库项换成 EM 先验更新（Saerens 等 2002）；用真实来源标签的上界 |
| 框架消融（B★ 前端） | A-2f-ctxn（即 MAIN）、A-2f-ctxn-g、CAET、A-SRC-2f、A-2f-EM、Oracle-A | 与第十四轮相同 |
| 其他组合 | KR+M、RVN+M、KRir+M、RVNir+M、QEir+M、GP+M | 说明迁移可以叠加在任意前端上 |

## 5. 指标与统计

- **绝对指标**：mAP、R1、R5、R10、mINP，单位 %。
- **相对指标**：相对 B★ 的 ΔmAP、ΔR1；有害替换率 harm，即 B★ 的 top-1 不是仅红外项的查询中，R1 由对变错的比例。
- **单元**：每个混合有 3 个拟合种子 × 5 个分配种子 = 15 个单元，报告单元均值。
- **组均值**：组内各混合的简单平均。
- **配对差**：每条查询先对单元取平均，再对组内混合取平均；然后按测试身份做身份簇 bootstrap（4000 次，种子 7），整组联合重采样，给出 95% 区间。
- **判定只用主口径**：完整测试图库、主选择规则。

## 8. 跑前登记的风险

1. **规模偏移，最可能出问题的是 C2。**
   - 门控在开发集 478 项（episode 中再随机丢 0–30%）的图库上拟合，测试图库约 1,473 项。
   - 图库越大，最近邻链接的身份准确率越低。1c 的数据是：训练身份 WCCN 下，约 160 项时 0.78–0.84，约 319 项时 0.75–0.76。
   - 准确率下降会同时带来三个后果：
     - 到完整项的最大链接余弦 f1F 变高；
     - κ̂ 变小，因为 κ̂ ≈ a·c；
     - 在无来源图库上更容易误迁移。
   - 所以 B 组损失可能大于开发集的 −0.07～−0.13，A 组增益也可能小于开发集。
2. **最终流程是事后选的**（§1.2）。
3. **只有一个数据集。** 第二数据集尚未核实可得性，论文要写明。
4. **s103 是新种子**，开发集上从未看过它的结果。
5. **数值环境不同**：AutoDL 上是 numpy 1.26.4、sklearn 1.7.2，沙箱是 numpy 2.5.3、sklearn 1.9.1。第十三轮 1a 的经验是 summary 的主要列逐位一致，AUC 列差 ≤ 0.006。
6. **测试集比开发集大约 3 倍**，运行时间和内存按 §9 的实测估计。

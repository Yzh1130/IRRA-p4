# 后续对照实验协议 v2：固定模型门控替换（B）与可靠性损失梯度隔离（A）

修订时间：2026-09-15（v1 同日写定后修订）。修订时两项实验均未运行、未看到任何结果。修订内容：(a) 实验 A 的结果判据去掉"贡献有限"的否定式结论与漂移量硬阈值；(b) 实验 A 的实现改为"主分支不动、辅助分支复用主分支 Dropout 掩码"以保持与旧 D 的兼容；(c) 实验 B 的固定权重校准与数据加权方式、复现核对与输出格式写明；(d) 补充单种子试跑与耗时/存储记录要求。v1 保留不改。

## 0. 共同规定

- 数据、划分、评估协议、11 个核心场景、退化随机种子 2026、统计单位（训练随机种子）与主网格相同。两项实验均为基于已有发现提出的后续对照，不是对未见测试数据的独立验证。
- 统计：同种子配对差值均值±标准差、t 型 95% 区间、改善数、精确双侧 Wilcoxon p；每项实验的主要检验各构成一个 Holm 族；区间不作多重校正；逐种子结果全部保存与报告。
- 顺序：先以种子 101 检查运行正确性、复现核对、耗时与存储；通过后完成其余种子。单种子结果不用于修改设计。
- 禁止：事后增改终点；以测试集选择固定权重；把结果写成"证明""排除"。无论结果方向如何，完整报告。

## B. 固定模型的门控替换诊断（只需推理）

问题：在同一训练好的模型上，可见光退化下的损失是否由门控在推理时的权重分配直接造成；受损模态在该模型上仍保留多少可用性。
对象：主网格已训练的 D 模型 10 个（种子 101–110，最终权重 last.pth 及随其保存的 configs.yaml）。E、F 各 10 个作次要对照，在 D 完成后进行。
步骤：

1. 复现核对：以原始学习门控在 11 个核心场景上重新评估 D_seed101，与 MAIN_GRID/metrics.tsv 逐场景核对 R1、mAP、mINP（预处理、图库与查询顺序、退化注入位置、退化随机种子、相似度与排序实现均沿用 test.py 与 Evaluator）。允许的差异仅为浮点运算误差（|Δ|≤0.01 个百分点）；超出则先解释或修复，不进入正式比较。
2. 特征缓存：固定模型与退化样本，每个场景抽取一次 RGB 特征、IR 特征（编码器输出、进入融合前）与文本特征；同一场景下的不同融合方式复用同一批特征，不重新抽噪声。
3. 融合方式：(i) 学习门控；(ii) 固定等权 [0.5, 0.5]；(iii) 训练内校准固定权重：该模型在训练集干净样本上的平均门控权重，按图像对计算（每个图像对计一次，不按文本条数重复加权），使用确定性评估预处理，逐模型保存；正式训练集包含原开发集 190 个身份，故称训练内校准。融合尺度（系数 2）、归一化与相似度计算与原实现一致。
4. 单模态诊断（分开输出）：(a) 单模态直接检索：以 f_rgb 或 f_ir 单独作为图像特征，绕过融合与门控；(b) 输入置零：与主协议相同的可见光/红外置零场景，经编码与融合。二者均不能无条件等同于真实信息量。
5. 输出：每个（种子, 场景, 方式）一行的 TSV（含 R1/R5/R10/mAP/mINP）；逐模型校准权重；复现核对表；运行记录（checkpoint 路径、配置哈希、代码提交、场景与随机种子、耗时与存储）。输出目录独立于历史产物。
   主要检验（Holm 族，m=2）：D 模型上"固定等权 − 学习门控"在可见光噪声聚合 R1（P1）与可见光模糊 R1（P2）上的配对差值。次要（描述性）：训练内校准固定权重的同一比较；无退化与红外退化场景上的代价；其余场景；E、F 的同一比较。
   解读规则：替换权重使 P1 恢复（差值区间高于零）→ 支持原门控相对所比较的权重产生了可避免的损失，限定在当前模型与测试条件内；替换权重未恢复 → 所测试的替代权重不足以恢复，不能直接认定主要原因是表征变化；仅部分条件恢复 → 如实报告条件差异，不推广至所有退化；同时报告无退化与红外条件下替换权重的代价。

## A. 可靠性损失的梯度隔离（D-iso）

问题：可靠性损失经评分器输入反传到共享编码器的路径，是否参与训练退化类型上漂移的增大与可见光失效。
配置：D-iso 与 D 逐键相同，仅在计算可靠性损失所用的 α_aux 时切断评分器输入到编码器的梯度；评分器参数仍受该损失更新；用于融合的 α（含 gate_base_grad_scale 路径）、检索损失与 MDRC 的全部梯度路径不变；τs、Dropout、归一化、目标构造、初始化、优化器与 checkpoint 规则不变。
实现约束：主分支代码路径完全不动（保留 nn.Dropout）；辅助分支从主分支的 Dropout 输出反推各模态各自的掩码（被丢弃单元为零），对 detach 后的输入重算并复用该掩码，使 α_aux 与 α 在前向逐位相等；RGB 与 IR 的掩码各自复用，不合并。隔离关闭时与旧 D 的前向、参数加载与随机行为完全一致。
正式训练前的检查（在可靠性监督已启用、评分器有有效梯度的训练状态下）：主分支与辅助分支前向权重一致（逐位）；仅反向可靠性损失时，编码器侧输入特征的梯度为零（逐位）、评分器参数梯度非零；检索损失与 MDRC 反向得到的编码器梯度与隔离关闭时一致（同设备、同精度下按合理容差比较，不承诺逐位）；隔离关闭时与旧 D 前向逐位一致；checkpoint 加载、初始化与优化器设置无额外变化。
种子：先 101（正确性、耗时），再 102–110；与 A、D 同种子配对。
主要检验（Holm 族，m=2）：D-iso 相对 A、相对 D 在 P1 上的配对差值。描述性：rgb_noise_010 与 rgb_blur_k7 的漂移量、目标与 α_rgb（逐种子与区间）；无退化、可见光组、红外组、10 场景平均。
解读规则：相对 D 漂移与失效同时减轻（P1 差值区间高于零，且噪声场景漂移量的配对差值区间低于零）→ 支持该路径参与失效与漂移增大，不单独证明反馈环；相对 D 未观察到改善 → 表述为"当前实验未获得切断该路径能够改善结果的证据"，是否可进一步判断其贡献大小依据效应量与区间，不凭不显著作出判断，不据此归因于 MDRC 或退化暴露本身；仅其一变化 → 按描述性结果报告；不设漂移量的硬阈值。

# RGBNT201-PEDES 外部验证预注册

> **本文件在任何 test 划分评估之前写定并提交。**
> “预测”小节为空时，`run_external_grid.sh --phase main` 将被拒绝执行。
> 这是有意的防护而非缺陷。

## 1. 判定规则（在任何测量之前写定）

### 1.1 前提一：模态任务效用严重不对称

以模态置零作为单模态检索能力的受控代理，在 dev2（30 个身份）上测量：

- `û_rgb` = `ir_missing` 场景的 R1 种子均值（热红外置零，等价 RGB-only）
- `û_ir`  = `rgb_missing` 场景的 R1 种子均值（可见光置零，等价 T-only）
- 效用比 = `û_rgb / û_ir`

| 效用比 | 判定 |
|---|---|
| ≥ 2.5 | 成立 |
| 1.5 – 2.5 | 部分成立 |
| ≤ 1.5 | 不成立 |

**阈值依据**：RGBT-PEDES 上该比值在测试划分为 3.85、在开发集为 2.68，
两者均观察到本文所述失效（可见光退化组分别为 −2.732 与 −1.895，
且分别为 10/10 与 3/3 种子恶化）。
2.5 取在已观察到失效的最小值 2.68 之下，作为“成立”的下界。

### 1.2 前提二：扰动敏感度与效用排序相反

在 dev2 上测量同强度扰动下两模态的干净—退化特征漂移量，计算
`drift_rgb / drift_ir`：

| 噪声场景下的漂移比 | 判定 |
|---|---|
| ≥ 1.5 | 成立 |
| 1.0 – 1.5 | 部分成立 |
| ≤ 1.0 | 不成立 |

**阈值依据**：RGBT-PEDES 上该比值为 σ=0.05 时 3.02、σ=0.10 时 2.75、
模糊 k=7 时 1.69，全部大于 1，即任务效用更高的可见光模态同时漂移更剧烈。

### 1.3 预测（依据上述两项前提的组合）

- **两项前提均成立** → 预测 A→D 的配对比较呈现与主数据集一致的方向：
  可见光退化组配对差值为负、红外退化组为正。
- **前提一部分成立且前提二成立** → 预测方向相同但幅度明显小于主数据集
  （可见光退化组的恶化幅度不足 −2.732 的一半，即绝对值小于 1.4）。
- **任一前提不成立** → 预测失效不出现，即可见光退化组的配对差值不为负，
  或其 95% 置信区间跨越零点。

### 1.4 三条辅助预测

1. **配置 E（温度软化）**：若失效出现，预测其相对 D 在可见光退化组上改善，
   且改善集中于该组、对红外退化组无可测量影响；若失效不出现，
   预测其相对 D 无方向性变化。
2. **配置 U（效用偏置）**：先验 u 由 dev2 重新估计，**不沿用主数据集的
   [0.7285, 0.2715]**。预测其在可见光受扰场景上缓解过度降权；
   在 `rgb_missing` 场景上，由于该场景漂移量极大而使常数偏置被淹没，
   预测其与 D 的差异不显著。
3. **绝对性能**：文献报道 IRRA 在该数据集上 R-1 为 37.92。
   预测本文配置 A 的 clean R1 落在 30–46 区间；
   超出此区间视为数据接入异常，须排查后重跑，不得直接采用。

### 1.5 证伪条件与结果解读

该数据集测试划分仅含 30 个身份，本节全部结果列为**验证性证据**，
报告效应量与置信区间，不作显著性判定，不进入正文的确认性统计结论。

两种结果都具有解释价值：

- 前提成立且失效出现 → 支持结论的外部有效性；
- 前提不成立且失效不出现 → 正面支持本文关于失效条件的刻画。

**仅当“前提成立但失效未出现”时，才构成对本文机理的反证。**
届时将如实报告，并重新审视机理的适用范围。

## 依据前提写下的预测

前提一部分成立（效用比 2.349，落在 1.5–2.5 区间）；
前提二未能按 1.2 节所要求的方式测量——阶段 1 仅训练配置 A，不产生特征漂移统计量，
测量脚本所用的性能代理在本数据集上不可用（见 2.2 节）。

按 1.3 节第三条规则，选定预测如下：

> **任一前提不成立** → 预测失效不出现，即在 RGBNT201-PEDES 的测试划分上，
> 配置 D 相对基线 A 在可见光退化组上的同种子配对差值不为负，
> 或其 95% 置信区间跨越零点。

三条辅助预测同时生效：

1. 配置 E 相对配置 D 在可见光退化组上无方向性变化——失效未出现则无可修复之对象。
2. 配置 U 在可见光受扰场景上与配置 D 的差异不显著；在 `rgb_missing` 场景上，
   因该场景漂移量极大而使常数偏置被淹没，预测其与配置 D 的差异同样不显著。
3. 配置 A 在测试划分上的 clean R1 落在 30–46 区间。本文注意到 dev2 上该值为 51.541，
   已高于该区间上界；该区间原以文献在测试划分上报道的 37.92 为参照设定，
   未区分开发集与测试划分。若测试划分亦高于该区间，本文将如实报告，
   并说明数据完整性已由划分统计量的逐项吻合独立确认
   （train 141/3248/3245、test 30/836/836），不将其作为数据接入异常处理。

## 3.1 超参数的处置

目标温度 T_r = 0.2 由主数据集的开发集选定后**直接迁移**，不在 dev2 上重新筛选：
它是本文冻结的设计选择，外部验证所要回答的是同一设置下结论是否成立，
而非重新调参后能否奏效。

效用先验 u **必须在 dev2 上重新估计**：它不是超参数，而是数据集的测量属性，
沿用主数据集取值等同于使用错误数据集的统计量。
估计方式与 4.1.3 节一致（模态置零代理 + 归一化），
结果写入 `frozen/FROZEN_HPARAMS_RGBNT201.json` 并在阶段 2 前冻结。

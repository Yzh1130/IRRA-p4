**主要终点（2 项，报原始 p 值）**
- A vs D，10 个退化场景平均 R1
- D vs E，同指标

**次要终点（族内 Holm 校正）**
D vs F、D vs U、三个场景组 R1（可见光退化组/红外退化组/双模态组）、无退化 R1、10 场景 mAP、10 场景 mINP、平均相对跌幅

**不做显著性主张（只报点估计与 95% CI）**
A vs E、A vs U、E vs F、E vs U

**探索性（只报效应量与原始 p，明确标注）**
逐场景结果、错配倍数 M、真实成像退化、DCAlign、RGBNT201-PEDES 全部结果

**统一报告格式**
配对差值均值 ± 标准差 · 95% 置信区间（t 分布）· 改善组数 · 双侧 Wilcoxon 符号秩 p 值。以效应量与置信区间为主，p 值为辅。

**种子数**
A/B/C/D/E/F/H1/H2/U 各 10（种子 101–110）；dev 网格各 3；DCAlign 各 5；RGBNT201-PEDES 各 10

**超参选择规则**
选择指标为 dev 上 10 个退化场景的平均 R1。3 个种子均值最高者胜；若两候选均值差 < 0.3 个百分点，取较小的 Tr。

**配置定义（锁死）**
- D：Tr = 0.1 固定，不参与筛选
- E：Tr 从 {0.2, 0.3, 0.5} 中由 dev 选定
- U：Tr = 0.1，与 D 相同，仅增加 log u 偏置
- 全部含门控配置共享 τs = 5、scorer_lr_multiplier = 50

**硬性禁止**
non-inferiority 检验、TOST、事后增加 seed、事后更换主要终点、事后设定任何界值、根据结果决定报告哪个指标。全文不出现“非劣”“等效”“equivalence”“TOST”。

**test 划分的首次访问时点**
仅在 `FROZEN_HPARAMS.json` commit 之后、最终训练完成之后。
